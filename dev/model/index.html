The Model

The MyJumpHiddenMarkovModel type holds a hidden Markov model of the daily growth rate of one asset. This page describes the model, the steps that build uses to estimate the model, and the fields of the model.

The hidden Markov model

On each day $t$, the asset is in one of $N$ states, $s_t \in \{1, \dots, N\}$, where $N$ is number_of_states. The states are ordered by growth rate. State $1$ holds the most negative growth rates, and state $N$ holds the most positive ones.

The state on the next day depends only on the state today. The entry $T_{ij}$ of the transition matrix $T$ is the probability of moving from state $i$ today to state $j$ tomorrow.

In state $k$, the model emits the growth rate

\[g_t = \mu_k + \sigma_k\, \xi_t\]

where $\mu_k$ is the location of state $k$ (1/year), $\sigma_k$ is its scale (1/year), and $\xi_t$ is a draw from a Student-t distribution with $\nu$ degrees of freedom. A smaller $\nu$ gives heavier tails. The jump settings ϵ, λ, p_neg, and N_tail are stored in the same model, and the Jump Episodes page explains them.

How build estimates the model

The build function estimates the model from the growth rates in five steps:

  1. States: We fit a Laplace distribution to the growth rates by maximum likelihood (laplace_boundaries). Then we cut the fitted distribution at its quantiles into $N$ intervals of equal probability. The $N + 1$ interval edges are the boundaries, from -Inf to Inf.
  2. State of each day: Each growth rate gets the state whose interval holds it (assign_states).
  3. Transition matrix: We count how often state $i$ is followed by state $j$, and divide each row by its total (estimate_transition). A state with no next day in the data gets a row of equal probabilities.
  4. Emissions: The location $\mu_k$ and the scale $\sigma_k$ are the mean and the standard deviation of the growth rates in state $k$ (estimate_emissions). A state with fewer than min_obs growth rates uses the mean and the standard deviation of all the growth rates. A state whose growth rates have a standard deviation below 1e-12 keeps its mean and uses the standard deviation of all the growth rates.
  5. Stationary distribution: We solve $\pi T = \pi$, with entries of $\pi$ that add to one, for the long-run fraction of days in each state (stationary_distribution).

The build has no random steps. The same growth rates always give the same model.

The build call

The required keys are growth_rates, number_of_states, and ν. Every other key is optional, and the comments give its default:

import JumpHMM

g = JumpHMM.excess_growth_rates(prices; rf = 0.0, Δt = 1/252);  # the growth rates (1/year)
model = JumpHMM.build(JumpHMM.MyJumpHiddenMarkovModel, (
    growth_rates = g,         # the growth rates (1/year), at least two values, all finite
    number_of_states = 100,   # the number of states, an Int64 of at least 1
    ν = 5.0,                  # the degrees of freedom of the Student-t emissions
    ϵ = 0.0,                  # the probability that a jump episode starts on a given day (default 0.0)
    λ = 1.0,                  # the mean of the Poisson episode length, in trading days (default 1.0)
    p_neg = 0.52,             # the probability that an episode day is in the negative tail (default 0.52)
    N_tail = 5,               # the number of states in each tail that an episode day can reach (default 5)
    Δt = 1/252,               # the time step of the growth rates, in years (default 1/252)
    min_obs = 2               # the fewest growth rates a state needs to use its own emission (default 2)
));

The build checks every key before it fits anything. The build throws an ArgumentError that names the key for an unknown key, a value of the wrong type, or a value out of range, for example ν = 5 (an integer) or ϵ = 1.5.

The probability that a jump episode starts on a given day has the key ϵ, typed \epsilon. The similar Greek letter ε is an unknown key.

Each step above is an exported function that you can also call on its own.

The model holds no risk-free rate. We pass excess growth rates to build, tune, and validate. The risk-free rate is subtracted once, when excess_growth_rates computes them.

Fields

The fields of a MyJumpHiddenMarkovModel are:

FieldWhat it holds
number_of_statesThe number of states $N$
laplace_μ, laplace_bThe location and the scale of the fitted Laplace distribution (1/year)
boundariesThe $N + 1$ edges of the state intervals (1/year)
transitionThe transition matrix $T$. Row $i$ holds the probabilities of moving from state $i$ to each state
stationaryThe stationary distribution $\pi$
emission_μ, emission_σThe location $\mu_k$ and the scale $\sigma_k$ of each state (1/year)
emission_nThe number of growth rates in each state
emission_fallbackA flag that is true for a state that uses the standard deviation of all the growth rates
νThe degrees of freedom of the Student-t emissions
ϵ, λ, p_neg, N_tailThe jump settings, explained on the Jump Episodes page
ΔtThe time step of the growth rates, in years

Changing a fitted model

The fields of a fitted model can be set by hand. Set the jump settings ϵ, λ, p_neg, and N_tail on a copy, so that the fitted model stays as it is:

model_with_jumps = deepcopy(model);
model_with_jumps.ϵ = 2e-3;      # the probability that a jump episode starts on a given day
model_with_jumps.λ = 40.0;      # the mean of the Poisson episode length, in trading days

A sector factor model needs more care, because the build computes ε_center from its fitted own models. The Sector Factor Model page explains the steps.
