Jump Episodes

A jump episode is a run of days on which the asset is in the tail states of the model, where the growth rates are large and negative or large and positive. Jump episodes give the simulated paths volatility clustering. This page explains the four jump settings and how simulate uses them.

The jump settings

The jump settings are fields of the MyJumpHiddenMarkovModel and keys of its build:

SettingWhat it measuresDefault
ϵThe probability that a jump episode starts on a given day0.0, no jump episodes
λThe mean of the Poisson episode length, in trading days1.0
p_negThe probability that a day of an episode is in the negative tail0.52
N_tailThe number of states in each tail that a day of an episode can reach5

The negative tail is the lowest N_tail states, and the positive tail is the highest N_tail states.

The length $K$ of an episode, in days, is drawn from a Poisson distribution with mean $\lambda$:

\[P(K = k) = \frac{\lambda^{k} e^{-\lambda}}{k!}, \qquad k = 0, 1, 2, \dots\]

How simulate uses the jump settings

We'll follow one path. The simulate function takes these steps:

  1. Day 1: The path starts in a state drawn from the stationary distribution, or in the state start if one is given, and the state emits a growth rate. Day 1 is never part of an episode.
  2. Episode check: On each later day with no episode under way, a jump episode starts with probability $\epsilon$.
  3. Ordinary day: If no episode starts, the next state is drawn from the row of the transition matrix for the current state, and the new state emits a growth rate.
  4. Episode days: If an episode starts, we draw its length $K$. On each of the next $K$ days, starting today, the state is drawn from the negative tail with probability $p_{\text{neg}}$ (p_neg) and from the positive tail otherwise, with each state of the tail equally likely. Each day of the episode picks its tail on its own, and the state of that day emits a growth rate.
  5. After the episode: The next day is checked for a new episode. On an ordinary day, the path moves on from the last state of the episode with the transition matrix.

An episode length of zero makes the day an ordinary day. An episode that would run past the last day stops at the last day. The episodes matrix of the result is true on the days of an episode.

Changing the jump settings

To change the jump settings, we build again from the same growth rates, with the new settings in the NamedTuple:

study_model = JumpHMM.build(JumpHMM.MyJumpHiddenMarkovModel, (
    growth_rates = g,
    number_of_states = 100,
    ν = 5.0,
    ϵ = 1e-3,       # the probability that a jump episode starts on a given day
    λ = 90.0,       # the mean of the Poisson episode length (trading days)
    p_neg = 0.52,   # the probability that an episode day is in the negative tail
    N_tail = 5      # the number of states in each tail that an episode day can reach
));

The build has no random steps. The new model has the same states, transition matrix, and emissions as a model built from the same growth rates without jump episodes. To choose ϵ and λ from the data, use tune, which the Tuning page describes.

The decoding functions decode, forward_filter, and log_likelihood do not use the jump settings.
