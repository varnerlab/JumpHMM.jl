## Global Constraints

- Branch: `refactor/course-style-0.5` in `/Users/jdv27/Desktop/julia_work/JumpHMM.jl`. Local commits only after Jeff's go-ahead at the start of execution. Never push or tag.
- `Project.toml` version `0.5.0`; Julia compat stays `1.9`.
- Style (spec, "The course style"): `mutable struct My…Model` with documented fields and an empty constructor `My…Model() = new()`; no inner constructors; all construction through `build(MyType, data::NamedTuple)`; input checks in `build` as plain `if` blocks throwing `ArgumentError`; documented top-level functions; explicit `for` loops and `if` blocks; no inner or nested functions, closures, `do` blocks, ternary chains, `x || throw` / `&& return` one-liners, or `kwargs...` splats; comments in the course voice (`# initialize -`, `# main simulation loop -`, `# return -`); course-format docstrings (signature, description, `### Arguments`, required NamedTuple keys, `### Returns`, `### Optional Arguments`, a short example).
- Files: `src/Include.jl` holds every `using`/`import`; `src/Types.jl` every type; `src/Factory.jl` every `build` method; one file per topic. `src/JumpHMM.jl` only includes files and lists grouped, commented exports.
- Examples in docstrings and docs always qualify: `JumpHMM.build(JumpHMM.MyJumpHiddenMarkovModel, (...))`.
- Same numbers: every comparison with the 0.4.1 reference uses `==`. A tolerance of `1e-12` is allowed only where a step below says so. Random draws are consumed in exactly 0.4.1's order (read the 0.4.1 source with `git show e5821a8:src/<File>.jl`).
- Rename table, applied everywhere: `N` → `number_of_states`, `n_paths` → `number_of_paths`, `n_steps` and `n` (path length) → `number_of_steps`, `dt` → `Δt`, `returns` → `growth_rates`, `market_returns` → `market_growth_rates`, `var1`/`var2` → `first`/`second`. Every other keyword keeps its 0.4.1 name.
- No compatibility shims, deprecation wrappers, or old names anywhere in `src/`.
- `MyJumpHiddenMarkovModel` has no `rf` field. Single-asset functions take excess growth rates, so the caller applies `rf` once. The multi-asset models take prices; `MyPortfolioModel` stores the `rf` and `Δt` it was built with, and its `tune` and `validate` use them, as 0.4.1 reused each fitted model's `rf`.

## Review Focus

- A model with `ϵ = 0` must not consume a random number for the episode check (0.4.1 short-circuits `ϵ > 0.0 && rand() < ϵ`); Task 4's `simulate/nojump` case pins it.
- A Poisson episode length of zero falls back to an ordinary transition on that day; Task 4's `simulate/k0` case (`ϵ = 0.05`, `λ = 0.5`) pins it.
- An episode that runs past the last day stops cleanly at `number_of_steps`; Task 4's `simulate/overrun` case pins it.
- States with fewer than `min_obs` observations get fallback emissions; Task 3's `fit_short` case (301 prices, 100 states) pins it.
- Out-of-range inputs to `build` (for example `ϵ = 1.5`, `λ = 0.0`, `N_tail = 0`) throw `ArgumentError` with a message naming the key; Task 3 tests each.
